# HR Insights Hub

You are a web designer specializing in HR analytics dashboards and reporting interfaces. Create an HTML/CSS/JavaScript website template for an HR analytics platform.

The template should include:

**Core Pages:**

- Dashboard homepage with key HR metrics (headcount, turnover rate, hiring pipeline, employee engagement scores)

- Employee data analytics page with filtering and sorting capabilities

- Recruitment analytics page tracking applicant sources, time-to-hire, and offer acceptance rates

- Compensation analytics page displaying salary bands, equity distribution, and budget utilization

- Retention analytics page showing turnover trends, exit reasons, and flight risk indicators

**Design Requirements:**

- Professional, clean interface suitable for HR professionals and executives

- Responsive design that works on desktop, tablet, and mobile

- Color scheme using neutral blues, grays, and accent colors (avoid overly bright or unprofessional colors)

- Clear typography and visual hierarchy

- Intuitive navigation that's easy to follow

**Functional Elements:**

- Navigation menu or sidebar for moving between pages

- Sample data visualizations (charts, graphs, tables) that represent realistic HR metrics

- Date range filters and export buttons where applicable

- Search and filter functionality for data tables

- Cards or sections that clearly separate different metric categories

**Technical Requirements:**

- Use semantic HTML5

- Include CSS for styling (can be in a `<style>` tag or separate stylesheet)

- Include basic JavaScript for interactivity (dropdown menus, tab switching, basic filtering)

- Make it template-ready so it can be easily customized with real data

- Include commented sections where dynamic content would be inserted

Provide the complete, working code that can be saved as a single `.html` file and opened directly in a browser. Ensure it looks polished and professional, ready to serve as a starting point for an actual HR analytics application.
